The Goal

Why this platform is being built and what problem it solves

EHS Rentals currently manages its rental operations across disconnected tools and manual processes. This proposal is to build a centralized, workflow-first web platform that brings every step of the rental lifecycle — from enquiry to payment — under a single, controlled system with full visibility, accountability, and automation.

The platform is not a simple CRUD application. It is built around tightly enforced workflow state machines, SLA timers, approval gates, document checklists, role-based task ownership, and real-time exception reporting.

📥Enquiry creation & assignment
📲Customer notification via Email & WhatsApp
📋Requirement collection (site, machine, commercial)
📄Quotation generation, approval & sending
🔁Quote follow-up, revision & won/lost tracking
✅Order validation & credit/background checks
🏗️Machine allocation & double-booking prevention
🚚SO execution: logistics, dispatch, gate pass, work start
🔄SO extension, de-hire & post-de-hire documentation

Business Goals

The measurable outcomes this platform is designed to deliver

⚡

Faster Quote Response

Reduce enquiry-to-quote turnaround time with automated SLA alerts at 10 min, 15 min, 1 hr, and 2 hr thresholds.

👁️

Better Sales Visibility

Track quote ageing, follow-up status, and lost reasons across all sales representatives in real time.

🔒

Controlled Approvals

Enforce manager and CFO approvals for quote deviations, PI sending, PDI, and commercial confirmations — nothing moves without the right sign-off.

🎯

Execution Discipline

Ensure documentation, dispatch, gate pass, and work start steps are never missed. Each stage has mandatory checklist gates.

🏗️

Asset Visibility

Track every machine's real-time status: Idle, On-Hire, Breakdown, Running, RTR, and Under Maintenance — with full status history.

💳

Billing Control

Track open SOs without invoices, PI revisions, and unpaid invoices. Never lose a billing cycle to missing documentation.

🔧

Service Quality

Track breakdown case ageing, engineer response times, repair actions, and customer feedback systematically.

📊

Management Dashboards

Dedicated dashboards for MD, SH, CFO, and each functional manager — with exception-first views and escalation lists.

03

Functional Modules

8 integrated modules covering the full rental and service lifecycle

📥
Module 01

CRM / Enquiry Management

  • Enquiry creation with SLA timers (10 min → 15 min → 1 hr → 2 hr alerts)
  • Customer auto-notification via Email & WhatsApp on enquiry creation
  • Structured requirement collection: customer, site, machine, commercial & safety
  • Quote generation: Standard, Deviation, and Revised quote types
  • Smart approval routing: auto-approve standard, Sales Manager for deviation, CFO for major exceptions
  • Quote PDF generation and sending via Email / WhatsApp
  • Follow-up tracking with call notes, next action dates, and revision history
  • Won / Lost tracking with mandatory lost reasons and reporting
🚚
Module 02

Sales Order Execution

  • SO acknowledgement to Ops, Service, and Finance teams
  • Logistics arrangement: transporter, vehicle, TPO, crane vendor
  • Document management: DC, E-way bill, Insurance, F32, Operator DL, Aadhaar, Experience Letter
  • Manager-approved document verification gate
  • Pre Delivery Inspection (PDI) with approval before dispatch
  • CFO-approved dispatch with photo upload and machine status update
  • Gate pass & induction proof upload with 24-hr exception alert
  • Work start confirmation: log sheet + telematics entry
  • SO extension management and de-hire execution with post-documentation
💰
Module 03

Billing & Collection

  • Per-cycle billing documentation: log sheets, telematics, service cases
  • Proforma Invoice (PI) generation synced with Zoho Books
  • CFO approval required before any PI is sent to customer
  • Invoice follow-up workflow and PI-to-invoice conversion
  • PI revision module with dispute reason, discussion notes, and promised date
  • Payment follow-up tracking against promised payment dates
  • Payment receipt confirmation and SO closure trigger
🔧
Module 04

Breakdown / FSM Case Management

  • Complaint registration against machine and SO with severity classification
  • Phone resolution attempt with close/escalate decision
  • Engineer assignment with spares inventory and task checklist
  • Travel and accommodation management for field engineers
  • Site check-in with GPS coordinates and machine photo upload
  • Machine repair tracking: issue list, fixes, parts used, repair photos
  • Customer feedback capture with authorised signature
  • Machine status auto-update post-case (Running / Breakdown / Under Maintenance)
🏗️
Module 05

Asset / Machine Management

  • Machine master with 6-state status tracking: Idle, On-Hire, Breakdown, Running, RTR, Under Maintenance
  • Machine allocation engine with double-booking prevention
  • Machine availability search by category and date range
  • Full status history audit trail with change reason capture
  • Inward workflows for New Machine, De-hire Return, and Repair Return
  • Inspection checklists: ODI, IIF, and PDI types
  • RTR (Ready To Rent) closure with Service Manager approval gate
✅
Module 06

Approval Workflow Engine

  • Quote deviation approval — Sales Manager
  • Major commercial exceptions — CFO approval
  • Document verification — Operations Manager
  • Pre Delivery Inspection — Manager approval gate
  • PI sending approval — CFO must approve before every send
  • Repair case closure — Service Manager conditional approval
  • Machine RTR status change — Service Manager approval
  • Pending approvals dashboard for each approver role
🔔
Module 07

Alerts & Escalation Engine

  • 18+ pre-configured alert rules across all modules
  • Multi-channel delivery: In-App, Email, and WhatsApp notifications
  • SLA-based triggers with graduated escalation paths (assignee → manager → SH → MD)
  • Enquiry-to-quote SLA: 10 min, 15 min, 1 hr, 2 hr thresholds
  • Quote follow-up ageing alerts: 1 day and 3 day escalation
  • SO execution exception alerts: dispatch, gate pass, work start, de-hire
  • Billing cycle alerts: PI not generated, pending CFO approval, overdue invoices
  • FSM alerts: complaint registered, engineer dispatch, check-in, repair done
📊
Module 08

Dashboards & Reports

  • Executive Dashboard: Today's enquiries, quotes, dispatch/gate pass exceptions, pending invoices, overdue payments, open breakdown cases
  • CRM Reports: SLA violations, quote ageing, lost reason analysis, employee response time
  • Operations Reports: Exception reports for dispatch → gate pass → work start → de-hire pipeline
  • Billing Reports: Open SO without invoice, invoice ageing, PI revision tracking, payment promise dates
  • FSM Reports: Case ageing by severity, engineer performance, fleet status overview

Architecture: Modular Monolith — Microservices-Ready

The system will be built as a modular monolith for MVP speed and operational simplicity. Each module is independently deployable and the architecture is designed to extract individual services as microservices in later phases without rewriting the business logic.
